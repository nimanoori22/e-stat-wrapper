#  Data
The statistical data provided by API can be found at the page below. Listed statistics are the statistical data currently provided in API.  
<[https://www.e-stat.go.jp/en/stat-search/database?page=1](https://www.e-stat.go.jp/en/stat-search/database?page=1)>  
However, please note that subregion and region mesh data are not listed.  
To get these, set "2" in the parameter, searchKind, of a search data is required. In addition, since there are the newest information of subregion and region mesh data is in version 3.0, use it when you get such data.
