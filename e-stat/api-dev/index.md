# Tips for developers
The links below are the list of helpful information for developers who develop any services with our API.
  * ## [Development Guide](https://www.e-stat.go.jp/api/en/api-dev/dev_guide)
[We introduce the information required for development with our API on this page.](https://www.e-stat.go.jp/api/en/api-dev/dev_guide)
  * ## [FAQ](https://www.e-stat.go.jp/api/en/api-dev/faq)
[This page shows frequently asked questions.](https://www.e-stat.go.jp/api/en/api-dev/faq)
  * ## [How to use API](https://www.e-stat.go.jp/api/en/api-dev/how_to_use)
[We introduce how to use API with some sample codes.](https://www.e-stat.go.jp/api/en/api-dev/how_to_use)
  * ## [GitHub](https://www.e-stat.go.jp/api/en/api-dev/github)
[We release the application developed with API on GitHub.](https://www.e-stat.go.jp/api/en/api-dev/github)
  * ## [Applications developed with our API](https://www.e-stat.go.jp/api/en/api-dev/case)
[We introduce applications developed with our API in this page.](https://www.e-stat.go.jp/api/en/api-dev/case)
  * ## [API Test Form](https://www.e-stat.go.jp/api/en/api-dev/testform)
[We prepared the test form that is able to confirm functions by entering parameter of API on a browser.](https://www.e-stat.go.jp/api/en/api-dev/testform)
  * ## [Samples](https://www.e-stat.go.jp/api/en/api-dev/app-sample)
[We have some sample applications with our API.](https://www.e-stat.go.jp/api/en/api-dev/app-sample)
